## 接入入口

1. 先看所选效果 GIF，读取 [接入契约](references/integration.md) 与 [统一参数](assets/effects.json)。参数 JSON 是数值来源；GIF 中的按钮、数字、背景、说明和循环空档仅用于展示。
2. 将需要的透明 PNG 及配置复制进目标工程自己的资源目录。路径均相对于本 Skill，不引用本机历史任务、聊天目录或网络素材。查看 `assets/manifest.json` 中的尺寸、透明范围及 SHA-256，保留 RGBA 与素材比例。
3. 按目标引擎的现有公开接口实现。参考 [采样代码](scripts/effect_math.py) 和 [运动规则](references/motion.md)，不要把 Python、GIF 播放器或某个历史引擎 API 强行带入工程。
4. 使用 [验收条件](references/acceptance.md) 在目标工程核对关键帧、实际速度、快速重复触发及退出清理。将基准差异和实机证据写入目标工程原有交付记录。

实现授权来自当前工程任务。本库不替代目标工程的模块归属、资源导入、保存或发布规则；不自行启动旧游戏、变更存档或修改其他项目。

## 不应在移植中丢失的约束

- **保住笔触。** 勾叉复用原透明纹理，不改成字体字符、光滑矢量图、白边贴纸、发光或重阴影。纸片统一使用附带的蜡笔涂色纸与浅色背面。
- **爆开不能一齐消失。** 前段快速弹出，后段减速下落、翻面，各片依自身寿命渐隐；不能因 300 ms 反馈结束或切题而清空尾部。离开场景、比赛中止等真正退出可以清理。
- **视觉不决定逻辑。** 计分、作答权限、题号、网络判定由工程现有规则控制。延长装饰余韵不能延长作答锁定、推迟换题或重复计分。
- **折页不泄露另一面。** 一次只显示一面内容，窄到折线后才换面。预览的 37→42 只是占位示例，不授权在记忆类玩法中引入提前展示、保留旧题或新的换题延迟。
- **GIF 是比对基准。** 实装使用透明精灵、粒子或组件变换。循环前后空档与演示复位不进入正式一次性效果。

## 附带校验

`python scripts/validate_library.py` 校验包内文件、素材摘要和采样行为。只需 Python 标准库；不操作游戏，不修改文件。

`python scripts/effect_math.py paper-burst --time-ms 300` 输出指定时刻的精灵状态，可用于目标引擎逐帧对照。需要核对 PNG 实际透明通道时运行 `python scripts/validate_library.py --images`，该选项另需 Pillow。
