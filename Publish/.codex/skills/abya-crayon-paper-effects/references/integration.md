# 工程接入契约

## 资源、坐标与层级

全部文件从 Skill 根目录按相对路径读取；仅复制实际使用的资源。`assets/effects.json` 列出效果、素材与参数，`assets/manifest.json` 提供文件 SHA-256、PNG 尺寸和 alpha 包围盒。

示例坐标系为 640×420、X 向右、Y 向下、时间秒。目标工程可统一缩放，但不能分别拉伸 X/Y 改变勾叉轮廓或纸片长宽比。秒与毫秒的转换只发生在接口边界。

勾叉原图为 1024×768 RGBA。预览先按 alpha 包围盒裁边，再按可见宽度缩放并居中；不是将整个带透明留白的画布强行缩放到可见宽度。允许图集裁边，但应使用 manifest 的 trim 信息补偿位置。原 ABYA 导入记录使用 PPU=16、中心 pivot；这是历史宿主设置，不是跨引擎要求。

PNG 采用普通 RGBA 素材。按目标引擎的混合约定统一处理 straight/premultiplied alpha，避免重复预乘；保持透明背景、Clamp 边缘与适当图集 padding。小尺寸下核对采样和压缩是否抹掉笔触或产生彩边。

推荐层级：背景 → 装饰纸片 → 交互控件/文字；勾叉作为主游玩区域反馈覆盖层，避开计时和比分。特效不捕获点击，不改变控件命中框。默认不新增全屏闪光、震屏、音效或触觉。

## 建议接口（逻辑约定，不是已存在的 API）

`play(effectId, anchor, visualBounds, eventKey, content?) -> handle`

- `effectId` 是四个库 ID 之一；`anchor` 为局部触发位置/组件。
- `eventKey` 用现有局次、玩家、题号、动作或状态版本生成，用于权威事件去重。
- `content` 仅供 page-turn 的旧面/新面组件或快照；内容须来自当前工程已允许显示的状态。
- `handle` 只管理表现生命周期；不能决定得分、题号或是否接受输入。

引擎适配器负责：资源句柄、坐标换算、时间推进、图层、裁切、池化与销毁。所有参数在创建时确定，不能每帧重抽随机数。

## 生命周期

### crayon-check / crayon-cross

收到已确认的正确/错误结果后，选择一个效果。每个玩家区域同一时间最多一个主勾叉；新结果可替换旧结果并重新计时。播放结束仅清理自身，不触发下一题。工程已有 300 ms 反馈窗口时继续由其规则推进。

### paper-burst

通常与正确勾同一次结果事件触发，锚定实际点击按钮上沿附近。paper-burst 的池与题目文本、勾叉组件分离：勾叉结束或普通换题时，旧纸片保留剩余寿命。仍可在结果页切换、场景卸载或中止时立即清理。

标准版固定 19 片；附带粒子初值用于复现选定 GIF。量产可更换随机种子，但保持配置范围、独立寿命与淡出曲线。连续快速触发需要预算时，优先减少**新发射**的次要纸片；避免整批清除仍明显可见的旧纸片。预算由项目性能与可读性实测决定，不凭 GIF 推定设备性能。

切题后不能让尾部遮挡新题或点击文字。锚点应转换到稳定的玩家区域特效层；不要把即将销毁的旧按钮对象直接当唯一宿主。

### page-turn

使用实时组件或内容快照实现单面可见的折页变换。面切换发生在参考曲线窄到折线的时刻；这只是视觉切换点，不能作为网络状态提交点。过渡结束保持新内容，不自动切回旧内容。

读取目标流程的内容展示规则再选用：菜单、卡面揭示等可以使用完整动作；已有即时换题或严格记忆曝光窗口的玩法不能直接增加本动画时长。先沿用玩法限制，必要时仅用于局外流程，记录适配差异。不要把 GIF 的演示复位或 37/42、提示语当成正式内容。

中断时停在**工程当前有效内容**，恢复正常尺寸与 alpha。不能仅因视觉播放被取消而回滚逻辑状态。

## ABYA 工程适配

若目标工程是 ABYA，依其托管 CLI/Runtime 与公开能力发现流程确认当前支持的 UI 图像、粒子、视觉缩放和生命周期接口。历史 `abya.ui.create_particle` 等实现记录不是当前版本保证。未验证支持时先给出等价适配并记录差异；不私自改 PB 源码、导入旧任务存档或直接写任务状态。

本包没有改动任何目标工程。接入是否可运行、低帧率表现和多端行为，都须由接入工程验证。
