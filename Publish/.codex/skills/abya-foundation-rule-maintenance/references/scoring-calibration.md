# 普通难度得分校准

目标范围读取生效得分规则。对象是熟悉基本操作、未专门训练的普通人类玩家，不是Bot或最优解；这是完整20秒样本的平均得分目标，不是每人每局保证，也不是显示上限/保底。允许单局0分或高于目标。

每个玩法自行选择简单的计分单位与固定奖励，不能统一照搬滑冰5分。优先用当前玩法普通节奏估算成功完成量，再定单次得分；需要反猜测扣分的玩法先保留其规则，连同失败率一起核算，不为统一分数静默取消。

可按一次尝试定义平均周期C（含观察、操作、移动、反馈和失败），成功率p、每次成功奖励r、失败扣分d，则预期得分约 `(20−必要初始展示)/C × (p×r−(1−p)×d)`。若C已按“包含重试直到成功的平均通关周期”定义，则成功量约 `(20−初始展示)/C`，不要再乘一次成功率重复扣除失败。

没有真人数据时，将C/p及预计得分标为制作初值或设计估算；写清假设与计算，保留待试玩项。有数据后按普通真人样本平均得分和分布调整。不能为了达到目标延长局长、压缩统一反馈、自动跳题、固定供题上限、强制封顶或向所有人补分。

滑冰已在V2.1文档及输入包应用：每完成一图固定5分，取消路线/计步奖励及重置的分数代价，未通关0分，重置仍保留原有耗时与本题重试。普通完成3–5图对应15–25分，设计周期约4.49秒时估算约22.3分；尚未证明真人平均完成量。逐规则应用状态、远端版本与核验依据以持久台账为准，不将文档已应用等同真人验证通过。
