# 按钮输入与判定反馈

本文件维护全流程键盘、输入提交、焦点和反馈时序。游玩界面的按钮类型、素材、尺寸、位置、字体与白圈几何统一见[UI布局](play-ui-layout.md)；来源及迁移要求见[按钮素材](button-assets.md)。准备／结算不套指定游玩皮肤，但仍遵循全流程键盘和提示。

## 外观与语义边界

同组答案同色、同尺寸、同厚度和图标重量，不用红绿／默认选中暗示答案。标签通常2–6字，陌生动作不能仅靠图标；固定动作位置与语义不随答案变化，手势期间不换义。标签与皮肤独立，不加塑料高光或写实木纹。特殊按钮审批按UI布局执行。

滑冰采用方向组与R重置；忍者跳跃Space跳跃，白圈显示空格键图形␣，不写“空格”二字。其他玩法不凭空新增动作。

## 全流程键盘与白圈提示

2026-11-11用户原话：“以后任何按钮都需要适配键盘按键，从现在开始的所有玩法都能够支持只通过键盘完成。且每个按键左上方都会有刚才设计的按键提示。”适用于本次及后续新设计/修订；不自动批量改写此前已交付文档。

- 每份文档给完整的页面—按钮—按键映射，包含开始/准备/取消准备、难度、添加/移除机器人、局内、结算、返回及必要弹窗；所有路径可脱离鼠标完成。保留可见按钮；键盘共用相同动作、权限、冷却、权威判定与去重，不得成为额外计分通道。
- 每个按钮左上方都有始终可见的白色真实按键提示，不因鼠标模式隐藏。局内白圈几何和字体按[固定尺寸](play-ui-layout.md#固定尺寸与字体)；局外以同白圈设计为基线，长键名的字号／尺寸需在该页文档明确并验证，不反过来改变局内固定规格。Space用␣（底部横线两端短竖向上），建议图形28×10、3px圆端线，读屏仍为“空格键”。白圈不是独立焦点，指针命中归原按钮；禁用仍可读，焦点不遮键名。
- 将白圈、轮廓、底座、阴影和状态预留范围共同纳入按钮可见边界和安全区；游玩界面的可用区域排除整个左侧按钮列，按[等距公式](play-ui-layout.md#几何与等距)居中。按钮之间不得重叠圆圈/命中，不能把新提示挤进说明或玩法区域。
- 离散动作在首次keydown提交一次，keyup只回弹；忽略repeat，锁定不排队。别名共用同一动作，键盘与鼠标同时触发按状态版本去重。持续动作须另写明确例外，松开/失焦停止。
- 默认Tab/Shift+Tab遍历启用按钮，焦点可见且顺序符合页面阅读顺序；当前页面的专用快捷键优先，未冲突的Enter可激活焦点按钮。专用键与焦点激活不得双提交；Space在忍者跳跃局内只代表跳跃，不触发另一焦点按钮。阻止已处理按键的浏览器滚动/默认click。
- 切页/开局/重开/失焦/弹窗/截止时清理未完成指针和按键状态，已按住的键必须松开后重新按下才可在新状态触发。禁用按钮、非房主动作和文本输入框中的字符不会被快捷键绕过；输入框编辑完成后可只用键盘离开并恢复操作。弹窗限制焦点与快捷键在其内部，关闭后恢复合理焦点。
- 推荐局外映射Enter准备/开始/返回准备、1/2/3难度、B添加机器人、F1–F4移除对应席位Bot、Esc返回/取消；具体页面存在冲突时由文档确定唯一映射并让白圈同步。F键等浏览器保留行为须在游戏获得焦点时验证能被拦截，不能只画提示。
- 一笔画等既有手势玩法仍保留指针方式；新稿/修订另定义等价键盘操作以完成同一挑战，不降低规则或把拖动改成逐格鼠标点击。须展开开始路径、方向移动、提交/取消以及失败与截止，不能仅写“支持键盘”。
- 验收从准备页到结算/重开完整走一次仅键盘流程，覆盖每个按钮白圈、焦点顺序、禁用权限、长按、别名、鼠标并用、失焦和跨页面旧按键。

## 提交契约

- 默认离散动作：主指针在启用按钮内按下显示按压，同键内松开提交一次；右键/额外指针忽略，触摸不依赖悬停，长按不自动连发。
- 外部按下移入、跨键松开无效；滑出即取消，滑回也不能补交。命中逻辑矩形不随动画移动。
- 手势绑定当前局、题目/动作状态和按钮；禁用、切题/页、失焦、取消、截止清除未完成手势。启用后不补发旧按下，需新手势。
- 按玩法定义次数/冷却窗口；锁定时后续双击/其他键不排队，不将“一题一次”强加给所有游戏。确需按住按钮持续动作时，文档明确其为离散提交的例外，写明按下启动、速率/上限、松开停止、滑出/失焦/截止取消；松开不再补交一次，仍不得使用拖拽或划线判定。
- 本地只先反馈触感，得分/成败由权威结果驱动。提交携带轮次与唯一动作标识，重复/迟到不套下一状态；Bot走相同合法动作，不直接写分数。

## 状态与反馈

下表涉及用户PNG的皮肤切换仅适用于游玩界面，其他界面保留自身常态/按下态设计；通用输入与反馈语义继续适用。

| 状态 | 共同表现 |
|---|---|
| 常态 | 使用对应用户常态PNG，保留原图配色与底座 |
| 悬停/焦点 | 保留原皮肤；焦点3px低饱和青绿环，纳入固定预留边界，不单侧外扩破坏等距，不放大挤邻键 |
| 按下 | 切换对应用户按下PNG，按UI布局的共同底边和高度差补偿定位；图标/文字中心向下且尺寸不变，白圈/命中框固定，不叠加额外压缩或动画位移 |
| 松开/取消 | 恢复对应常态PNG；指针仅合法松开提交；键盘遵循首次keydown提交，keyup仅回弹；取消不触发判定 |
| 禁用/待回执 | 在既定皮肤上降低强调并保留清楚标签/白圈；这是未另给素材的派生状态，不把按下图误作禁用图 |
| 成功/失败 | 按下节复用库内纸片爆开及游玩区勾/叉；不能仅以小徽记、文字或分数变化替代 |

禁用原因在已有对应状态容器内表达，不为此新增提示条。无成败语义的准备/添加机器人等按钮使用触感与状态变化，不播放答题勾叉；局内动作是否形成一次真正成败，由本玩法明确。

## 统一正确/失败反馈

### 来源与职责

F1负责判定触发、显示位置、逻辑锁和切题；动效素材、运动曲线与粒子参数统一来自[abya-crayon-paper-effects](../../abya-crayon-paper-effects/SKILL.md)。新稿及反馈修订必须读取该库的接入契约、effects.json和相关GIF；不再自行设计星星粒子、逐笔勾叉、纸花或翻页曲线。库版本/参数以当次实际读取为准，下面基准对应1.0.0。

| ID | 使用位置与条件 |
|---|---|
| crayon-check | 权威正确结果，在PLAY-CONTENT内居中显示对应的透明勾，材质按下节适配 |
| crayon-cross | 权威错误结果，同区域显示对应的透明叉，材质按下节适配，不播放纸片爆开 |
| paper-burst | 正确结果的组成部分，锚定实际交互按钮上沿或判定对象/提交点 |
| page-turn | 可选：小型题目卡片容器切换新题，适用条件见下节 |

勾叉按alpha可见包围盒等比缩放，最长可见边约为PLAY-CONTENT短边的60%；保持库内整体轮廓、判定颜色与整枚弹出/回落/淡出，不改成字体字符或逐笔绘制；平面材质范围见下节。限制在PLAY-CONTENT内，避开说明、时钟、按钮与比分，不高亮另一个正确答案。纸片在纸面之上、文字/交互控件之下，沿用库内纸片形状及正反面关系，材质按下节适配；不让特效捕获点击或移动命中框。

### 特效材质适配

用户最新要求背景与玩法统一平面纸片，因此本系列在复用库内四款效果时使用平面材质层；这是对旧“保住蜡笔笔触”的限定覆盖，**不修改共享库，也不新增另一套运动效果**。`crayon-*`是既有ID，不代表必须在本系列展示蜡笔外观。

- 保留源勾叉的主要轮廓、比例、锚点及绿/红判定语义；去除内部颗粒与漏白、边缘碎屑，改为清楚的平面填色。纸片保留原形状与正反面深浅关系，改用无颗粒色块。不能改成字形勾叉、星星爆炸、发光或厚浮雕。
- 动画时长、曲线、粒子初值/寿命、翻面及下节逻辑窗口仍来自原库；翻页仅使用当前题卡的平面外观，不带入GIF演示UI。
- 已核对的1.0.0只有蜡笔原素材，**没有现成平面皮肤**。成稿必须把这一点及所需适配资产写明；已有适配文件则记录路径/摘要与源ID映射，未制作则列为资源制作项，不能声称已入库、已接入或无差异复用。源纹理/GIF仅作轮廓与运动基准，不让接手工具默认把旧颗粒直接用于运行画面。

### 逻辑窗口与装饰生命周期

从收到有效权威结果起记t=0。判定锁F仍为一般题型500ms、二选一默认300ms，正确错误同长。当前库勾叉各300ms，使用原速；这是动效时长，不是所有题型的锁时长。

| 事件 | 一般题型F=500ms | 二选一F=300ms |
|---|---|---|
| 正确 | t=0启动paper-burst；t=200启动crayon-check，t=500结束主判定窗口 | t=0同时启动paper-burst与crayon-check；t=300结束主判定窗口 |
| 错误 | t=200启动crayon-cross，t=500结束主判定窗口 | t=0启动crayon-cross；t=300结束主判定窗口 |
| 推进 | F到达后按规则切新题或重试本题 | 同左 |

- paper-burst独立生命周期按库执行，当前基准最长约1020ms。F结束或普通切题不能整批清空余韵，也不等待所有纸片消失才开放下一题。纸片挂在稳定的玩家区域层，不随旧题容器销毁；快速连续触发按库预算约束处理，文字始终可读。
- 状态为可操作→待权威判定→判定锁→新题/原题重置→可操作；锁内不排队、不提前展示下一题。失败去向由[规则设计](image-to-game.md)决定，装饰尾部不能改题号、得分或操作权限。其他玩家独立继续，Bot按同档F等待，不等待粒子尾部。
- 权威端也至少保留F，下一动作须同时满足本端窗口完成及权威就绪，两端不串行叠加成2F。用真实经过时间推进，不依赖动画回调；合法结果只计分一次，迟到/重复结果不重播。
- 总局计时不断；截止优先，停止新计分/切题/重试并进入结算，保留已生效分数。结果页切换、场景卸载或比赛中止可清理所有效果；普通切题只结束所属主勾叉，不误清纸片尾部。
- 静音保留视觉。减少动态效果时使用同一平面适配素材，降低运动、不改变逻辑F，并在文档注明无障碍适配差异；不另加错误等待。

### 可选卡片翻页

适用于题目承载在独立小型UI卡片中的换题，例如单张数字/符号卡；不默认翻转整个玩法盘面、固定背景、HUD或按钮。解谜失败留在本题时不播放“下一题翻页”。每份文档明确page-turn启用/不启用及原因；没有合适卡片时省略此效果。

库基准是单面可见、收窄为折线后换面再展开，动作约860ms；1500ms预览包含停留，不能直接当切题等待。严格F窗口内若启用，复用同一归一化曲线，将动作段整体映射进F，与主判定并行，不追加等待：只翻卡片容器，旧题面按曲线收起，换面后暂为空白纸面，到F且权威就绪才显示下一题并恢复输入。不得在折页中提前展示新题；勾叉位于不随卡片折叠的独立覆盖层。文档写明这是相对库原速的时间/内容适配，并检查缩短后仍可辨识。

若这种容器适配不自然、遮挡关键记忆或不能满足可读性，局内不启用page-turn，保留即时切题；局外允许完整动作且不涉及题目曝光时可复用原速。禁止为了展示翻页而自行延长锁定或提前让玩家/Bot看到新题。中断后恢复当前逻辑内容、正常尺寸和alpha，不回滚题目。

### 文档与验收

正文记录库名/版本、所用ID、触发与锚点、显示范围/层级、F、视觉余韵和翻页选择；随包素材按[交接契约](abya-input-contract.md#特效库交接)处理。引用库的运动规则与验收要求，检查平面素材与源ID映射、余韵独立淡出、连续触发、切题/截止清理、翻页单面和曝光时刻；未实机验证不写接入通过。

按钮触感音沿用统一柔和短“嗒”：有效按下最多一次，松开/取消不补音，无效输入静默；每个权威结果最多一次判定音。特效库不额外新增音效、震屏或触觉，宿主静音仍保留完整视觉。
