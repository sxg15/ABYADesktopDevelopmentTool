# 系列视觉与UI

本文件维护主题、材质、背景及内容边界；所有UI几何、字体与组件两态统一见[现行布局规格](play-ui-layout.md)，输入与特效见[按钮与反馈](button-system.md)，来源见[图片索引](ui-reference-guide.md)。配色初值不等于可自行改变固定布局。

## 风格与分层

现行风格是**平面卡通纸片**：干净色块、清楚轮廓、轻薄叠层、短距离浅阴影。背景、玩法物件、按钮及UI不使用蜡笔颗粒、粗纤维、漏白油墨、蜡染或写实布纹；不添加参考游戏角色或蜡笔吉祥物。纸感来自裁切边、折角背面、压边和浅厚度，不能只靠噪点。固定R15原文件保留原貌；特效库的平面材质适配只在[F1](button-system.md#特效材质适配)定义。

Pokémon Friends用于功能组件与背景弱化方式，《卡比的美食节》仅借成组卡片/徽章组织；不复制其角色、商标、高饱和配色或厚重3D。

| 层 | 职责 |
|---|---|
| BG-01／R15 | 整屏固定原图，水平居中、下边缘锚定，适配见下文 |
| PLAY-PAPER／HUD-02 | 左游玩与右比分的完整不透明底板；颜色与印花来自下文四套主题 |
| 边缘装饰 | 裁边、折角、胶带、装订或云朵叠纸；从属于底板，不挤占功能区 |
| 玩法对象、HUD-01、时钟、按钮 | 独立可更新的清晰内容；浅色卡片与较深底板分离，不能把内容烘焙进背景 |

### 边缘装饰与玩法空间

- 使用所选主题的装饰语法；允许为玩法密度裁减、移到空闲边缘或轻微换位，不混贴四套边饰。背景与操作对象的颜色层级保持不变。
- 装饰围绕底板边缘组织，中心留给题目；保留纸片短浅阴影、薄侧边、折角背色、云朵下部稍深等轻细节。背景装饰的明暗差低于功能组件，不堆深阴影或厚浮雕。
- 明确功能内容排除区：时钟、说明、按钮、比分和路径优先。装饰放在这些元素下方也不能遮到文字、压边或命中区；空间不足时缩减装饰，不挪动固定外框来让位。四边露底及中缝规则见固定布局。
- 印花只装饰，不伪装成可点击节点或路径；笔记横线、小花和云朵弱于真实玩法对象。与机制图案相似时降低密度/对比，必要时局部清空。

## 界面内容与留白

2026-11-10用户明确要求：**不要擅自添加额外文字或文字容器**。仅展示当前玩法已确定的必要内容；说明归HUD-01、时钟归TIMER-01、比分归HUD-02，玩法对象按机制呈现。顶部轮数为2026-11-12用户明确指定内容，按[UI布局](play-ui-layout.md#顶部信息栏)显示真实当前轮数；不自行增加除此之外的“已盖x/N”等进度、下方教程、口号、提示条、重复说明面板，也不为填满空白添加内容。规则确需的状态优先在已有对应容器内替换文字，不另造容器；必要操作按钮只在确有动作职责时保留。

本次一笔画网格下方保持留白，不放进度字、补充说明或重置按钮；提前松开已承担失败重试。移除这些内容后，把空出的底部空间纳入游玩区域，网格在顶部说明下方的可用空间内向下居中，不保留不存在控件的占位；两栏外框和四边5px仍固定。此项不删除其他玩法有明确职责的操作按钮。生成参考图和开发文档须同步核对文字清单，不能把生图自行补入的标签升级为需求。

### 区域边界与等量留白

区域定义、按钮左下等距、主体上下／左右等距和无按钮取消占位统一按[几何与等距](play-ui-layout.md#几何与等距)执行。无按钮时主体水平居中于整个左侧大区域，垂直方向仍避开顶部UI。运行画面不加入测量线或评审说明。

## 固定横屏布局

固定R15底图、四周露底、左右分栏及内部UI的精确坐标和适配公式全部由[布局规格](play-ui-layout.md#坐标与固定外框)维护。题卡翻转、人数变化或装饰不能改变两栏。PLAY-PAPER是左侧大区域，PLAY-CONTENT是实际玩法主体，两者不能混用。

准备／结算保留固定背景与两栏覆盖结构，内部组件按页面职责设计，不强制套游玩按钮和顶部三项。标题放准备页，不占局内倒计时位置。

## 容器 HUD-01 / HUD-02

顶部倒计时、教学和轮数用用户指定容器（见现行UI布局）；右侧比分也有完整容器，不能裸放文字或只画网页分割线。HUD-01按用户指定教学图，题卡及比分行使用浅奶油面；HUD-02整栏底色使用所选主题右底板，不能与这些卡片全部同色。

| 属性 | 共享设计值 |
|---|---|
| 轮廓 | 通用题卡设计初值圆角24、3px暖褐边#A47A53；指定UI组件按布局规格及原素材，不能用此表覆盖。功能文字深褐#53412F |
| 内沿 | 浅色细压边；主题虚线属于底板边饰，不强制每张卡重复缝线 |
| 阴影 | 向下5px浅暖褐，弱于按钮底座；外框阴影裁切在第二层内 |
| 面与文字 | 题卡/比分保持干净色块、圆润中文中粗/粗体；顶部指定容器原有条纹/斜纹直接保留，不用旧通用无纹理规则覆盖 |

边框用九宫格或等效伸缩，保持角部和线宽；文字、数字及背景图案独立排版。题卡按玩法需要使用，不给所有玩法强加巨大卡片；尺寸由功能内容决定。

## 资产拆分与视觉核对

四张认可图是带UI的设计参考，不是可直接贴满屏的运行背景。交付明确所选主题、配色、底纹密度、边饰位置与排除区；制作时拆出无字PLAY-PAPER、右底板、边饰与独立功能组件。不得把示例19、12秒、名字、座次和分数写死进游戏，也不得让这些示例改动实际规则。纸面和底纹保持显示尺度，边饰独立锚定，避免整屏截图拉伸。

验收重点：正常尺寸下操作面与底板分明，装饰有轻层次且不遮挡，背景没有粗纤维/蜡笔纹理。隐藏玩法对象与内部控件后，完整第二层仍在；再隐藏两栏及其底衬才露出完整R15。四边5px与同视口只渲染R15时对应区域一致；16:9顶边浅黄、底边珊瑚，不用纯色线冒充。生成参考未保证精确像素或实机通过，制作端按公式和遮挡检查提供证据。
