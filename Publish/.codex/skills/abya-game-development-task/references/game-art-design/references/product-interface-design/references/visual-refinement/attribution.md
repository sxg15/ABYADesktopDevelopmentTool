# 来源与适配说明

本模块参考用户提供的 refactoring-ui-skill-main.zip（包内版本 0.1.0，作者 Edison Li，
项目 https://github.com/edisonmbli/refactoring-ui-skill），尤其是层级、排版、颜色、
审查清单与过度修正案例。该项目是对 Adam Wathan / Steve Schoger《Refactoring UI》
的非官方整理；作者或原书不为本适配版背书。

规则已经按产品任务、桌面/游戏平台和现有要求追踪契约重新组织。三色上限、单页
唯一主操作、固定五级阴影、固定视口和逐项规则编号不作为通用硬性条件。
不复制书中图片或正文；上游仓库许可声明保留在 [LICENSE.upstream.txt](LICENSE.upstream.txt)。
Node 辅助工具为本项目重新实现，替代上游 Python 导出与对比度辅助工具；不依赖
Tailwind 或 Python，不能将机器检查解释为设计认可。

对比度依据：https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html
规范适用性和文字大小由目标平台确认；中文和特殊字体还需实际检查。
