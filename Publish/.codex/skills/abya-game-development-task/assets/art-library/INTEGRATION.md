# 表现配方接入

这六个配方提供可运行 Web 演示、确定性参数采样和源码；未声明 Abya Player 实机通过。
源码由本项目编写，可在 ABYA 项目中修改、组合和分发；外部素材需要另行记录来源。

使用 preview.html（通过本地 HTTP 服务打开）预览，哈希参数可选 press/selection/panel/reward/hit/aura。
effects.mjs 的 sample 返回位移、缩放、透明度、光晕和旋转；style 是 Web 渲染适配层。
参数 strength 建议0至2，distance 为预览像素；接入原生时改成目标空间与实际尺寸。

## 原生接入

先发现当前 Player 的 CustomUI/Lua 及 ParticleEffect 能力，用实际 schema 建立映射。
UI 位置和比例从原始状态计算，取消时恢复原值；光晕应由已支持的材质或独立表现层实现。
一次性与持续粒子分别使用现役 ParticleEffect 类型；本地与网络 Prefab 分别验证。
共享资源只读，在游戏副本内改造；保存源码、版本、改动理由和依赖。
没有对应能力时记录缺口，不以直接修改业务结果替代效果接入。

## 生命周期与测试

业务逻辑确认结果后触发表现；表现完成、业务提交与资源释放分别处理。
每次运行持有独立句柄，重复触发明确选择替换或叠加；停止和销毁必须清理。
持续状态只有收到状态结束或取消事件才释放；视觉随机与规则随机分离。
测试正常播放、重复触发、中途取消、对象销毁、输入恢复、保存冷加载。
联机游戏逐端验证权威事件与本地表现，不能继承 Web 预览的验证结论。
