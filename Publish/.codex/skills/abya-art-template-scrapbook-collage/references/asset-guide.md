# 分层资源与实现

所有纸面、撕边、胶带和贴纸由本模板自制的 SVG 构造；PNG 为透明或平铺运行资源。未复制网站示例图，也不分发平台字体。
这些素材用于屏幕 UI，不用于世界格子：生成与导入采用 pixelsPerUnit=1，pivot={x:0.5,y:0.5}，原始尺寸保持不变；节点布局决定实际显示大小。世界对象使用时重新确定比例和接触点。
`assets/design-tokens.json` 定义颜色和反馈职责；`assets/specimen.json` 是隔离小样的几何、数据和状态来源。后续任务复制并版本化自己的配置，不直接修改已引用模板快照。

图层顺序：背景纸纹 → 外围装饰 → 操作面板与格子 → 独立文字 → 非命中反馈。胶带只贴边缘，不覆盖标签；装饰倾斜只改变装饰节点。
相同素材按实际显示比例使用；细边框采用节点几何，不拉伸整屏截图。纯装饰关闭输入命中，文字保留原生文本。
图片导入后使用公开资源赋值、读回和截图验证；资源文件存在不代表已经绑定。
字体按运行包实际资源核对并查看样字。模板没有打包 SourceHanSans 字体文件，也不保证任意 Player 都有该资源。

小样中的模拟排行只有展示作用。状态按钮用于隔离检查；移植到游戏时由该游戏实际事件驱动反馈，不照搬调试按钮和固定数据。

## 实机适配备注

本次 Player 的设计分辨率为 1237.48×693.360046，运行根画布为 1920×1080；
1280×720 设计配置到存档的 x/y 映射分别为设计分辨率除以基准尺寸，文字字号映射为 1.5。
这些是本次运行包的适配结果，不能写成跨项目规则；更换包或根画布后重新查询并标定。
该包运行时 `UIText.size` 与几何 size 写入冲突，故预配置 3×3 和 4×4 文字节点并切换可见性。
未修改 Player，也未用默认字体或自动字号掩盖差异。
`specimen-model.mjs` 生成共享布局；`specimen-lua.mjs` 生成按钮事件源，需要真实 nodeMap 和查询得到的画布适配。
不要把本小样 GUID 当成其他任务的节点 ID。资源导入回执和实际创建节点返回值是映射依据。
