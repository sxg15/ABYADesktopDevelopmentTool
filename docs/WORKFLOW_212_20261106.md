# 工作流 2.12 实施与验收

本次实施范围为执行期限取消、自动测试流程与公共动作库、美术/特效复用库。
Abya 引擎 CLI 的逐帧状态、完整重建、新输入或网络能力由同事负责；本次未修改 AbyaPB 源码。

## 已实现

- executionTimePolicy=unlimited：目标、工作项、轮次、恢复、收尾均不再按耗时中断；耗时继续用于统计。
- 旧任务打开/恢复托管终端时幂等迁移时间策略，保留批准、成果、未知写入、任务/会话身份和其他固定契约；运行中任务不热迁移。
- 明确废止旧 Skill 时间额度的 developer instructions；基础预检取消180秒总期限，发布试跑取消四小时门槛。
- 计划提交前提供绑定需求 hash 和实际原文的测试计划；不允许预填通过结论。
- 场景 v3 提供角色映射、30个公共动作映射、按键/拖拽组合、前序结果引用、范围及存在性断言。
- 各角色必须包含观测断言；执行前核对当前候选和当前实例能力，缺项如实拒绝。
- 保存场景、解析后参数、请求身份、完整响应及其指纹；未知写入不重放，失败留证；虚拟输入使用独立作用域并执行有回执的清理。
- 美术库支持带文件 hash、依赖闭包、参数、生命周期、兼容性、许可和测试说明的源码/资产包。
- 六个随包原创配方：按钮按压、选择高亮、面板转场、资源到账、命中冲击、持续状态光环。
- 随包配方提供交互预览和完整源码，标记为可用参考；没有伪造策划认可或 Abya 实机通过。
- 导入脚本只作为文件处理，UI 仅在隔离 iframe 中运行可信随包预览。

原生组件测试通过实际便携 App 的服务入口验证任务策略、脚本部署、资源包往返、文件指纹和批准隔离。
