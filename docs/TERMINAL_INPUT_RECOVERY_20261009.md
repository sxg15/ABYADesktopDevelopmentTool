## 修复内容

1. 历史回放改为去除 ANSI 控制序列的文本。旧光标查询、设备查询、输入模式和窗口控制不再送入新的交互终端；原始日志仍保留。
2. Codex/Grok 管道写入和窗口尺寸调整通过 `spawn_blocking` 执行，避免 Windows 终端的阻塞操作占用界面或异步工作线程。
3. 前端连接未完成时不发送窗口尺寸更新；连接完成后使用最新尺寸，并恢复输入焦点。“继续任务”后也恢复焦点。
4. 模型暂停但终端仍连接时，暂停按钮仍可用，以便关闭并重新连接失效终端。
5. 固定最小 portable-pty 补丁到 `src-tauri/vendor/portable-pty`，使用 Cargo patch 接入，保留 MIT 许可证与 `ABYA-PATCH.md`。不修改全局 Cargo 缓存，不重写完整 PTY 驱动。

以上修复处理检查中发现的启动链路风险，不修改游戏需求、计划、审批或模型配置，也不反复重发“继续”。
