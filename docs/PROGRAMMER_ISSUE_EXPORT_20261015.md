# 程序问题 Markdown 导出（2026-10-15）

## 使用入口

- 红色任务指引和 Lua 阶段提醒：导出程序问题汇总（MD），包含本任务所有未解决的源码／构建包问题。
- 源码／构建包问题卡片：导出此问题（MD），也可导出已解决问题的历史记录。
- 导出后自动定位文件；界面显示保存路径并提供“在文件夹中显示”。文件管理器失败时不丢失已保存的文档。

文件位于任务工作目录的 `artifacts/game-development/reports/`，文件名包含记录版本和唯一标识，每次导出保留独立快照。
内容包含任务与构建上下文、问题描述、影响阶段、受阻操作、处理方案、恢复条件、复验结果及关联证据记录。
缺失信息不补造；旧记录推断的归属明确标注“疑似”。证据附件不会打包，提供文档给维护人员时可另外附上相关文件。

## 行为边界

按界面所见记录版本和精确问题 ID 导出，过期记录要求刷新；不自动继续任务或修改问题、阶段、审批状态。
导出不依赖原生 AI 连接，已结束任务仍可导出历史。Markdown/HTML 片段以安全的动态代码围栏保留为文字。
原生适配器在阻塞工作线程执行，业务校验和文件输出由 TaskService 负责。
