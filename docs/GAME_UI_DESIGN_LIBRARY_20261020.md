## 候选参考

[参考库指南](../.codex/skills/abya-game-development-task/references/game-art-design/references/game-ui-design/references/ui-reference-library.md)
包含 7 条候选：2 个外部风格条目、2 个官方游戏 UI 准则、3 个原创结构模式。
类别为布局/信息组织、视觉风格、组件/状态反馈；每条记录来源、适用输入/密度、借鉴、适配、不采用及限制。
三条原创模式提供带文件身份的本地 PNG 与 SVG 示意，明确不是游戏截图、成品组件或策划认可。

| 情况 | 检索与设计行为 |
|---|---|
| 缺 UI 类型、输入、密度或范围 | 返回缺项，不从空查询推导默认风格 |
| 高密度战斗 HUD | 排除来源不适用的整屏纸风格；保留布局/反馈参考 |
| 仅借纸纹，品牌锁定 | 只给局部材质，明确保护品牌、文字和布局 |
| 局部背包焦点/导航 | 只给局部借鉴，不退回整页重排 |
| 策划指定外部来源 | 在适用候选中优先；不会越过任务限制 |
| 原创示意或外部指南 | 维持候选身份，不产生 artTemplate、采纳或认可记录 |

离线查询脚本只读取本地索引并输出候选及匹配/不匹配理由，不执行来源内容或联网抓取。
检索结果仍需实际查看有关原文、图片或示意，再形成当前任务的设计决定。
网页版式和营销结构不直接用于游戏；CSS 和英文推荐字体不是 Player 中已实现的能力。

## 保留边界

本轮没有新增数据库表、公开 CLI 命令、审批节点或参考库管理页面。
认可案例仍由策划明确满意后收录；外部参考与原创模式均未冒充该类案例。
原拼贴模板的小字号差异和编辑入口问题继续保留，本轮内容更新没有修复 Player 字体或增加纸雕引擎能力。
使用效果须在实际游戏任务中继续审阅；查询、部署和测试通过不等于已证明 Astra 成品的审美质量提升。
