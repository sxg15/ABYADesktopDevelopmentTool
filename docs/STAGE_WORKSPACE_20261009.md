# ABYA开发工具0.3.0更新说明

日期：2026年10月9日。制作工作流版本：1.3.0。

本次更新落实已讨论的执行计划。制作阶段、当前对话步骤和终端设置分别展示，策划可以直接查看阶段成果并处理当前问题。

## 已完成内容

- 制作流程顶部提供七个可点击阶段，区分正在查看和当前执行阶段。刷新保留所选阶段，窄窗口自动换行。
- 阶段页面集中展示成果文件、草稿、问题、问答、迭代和确认记录。文档通过资源管理器定位，已确认版本与批准历史保留。
- 顶部原有对话步骤接收本轮计划，支持CLI登记步骤并关联工具活动。调整顺序时保留活动记录，迟到事件不会切回旧轮次。
- 终端增加模型、思考强度和权限快捷设置。权限提供AI自动审核与完全同意；设置通过原生接口应用，并在重连后保留。执行中可选择下一轮应用，或暂停并应用。
- 按钮提示优先放在上方，支持键盘聚焦和窗口边缘调整。
- 更新AI工作流入口、报告模板、自动续接提示和界面文案，按结果、原因、下一步说明进展。
- 草稿可以在提交确认之前登记。阶段问答只重新检查相关阶段及其后续工作。
- 模板选择随文档确认一起保存；已有明确批准依据的模板可补登记。问题可指定影响阶段及阻止的操作，允许提交修正文档，同时保留阶段通过所需的检查。
- 修正已在执行却显示未开始的问题。兼容的工作流升级保留原批准、版本和迭代记录。
- 增加时间汇总，显示已记录的执行、工具、答题等待、文档等待、暂停和连接区间。同类重叠区间合并，缺失时间显示未知。
- 整合工程已有的终端输入恢复和指定窗口录制修复。

## 验证结果

- 前端54项测试通过，工作流及CLI检查通过，生产构建成功。
- Rust格式检查与Clippy通过；Rust库118项测试、CLI2项测试通过。
- 单独运行指定窗口遮挡录制测试并通过，核对了实际捕获画面。
- 在独立测试数据中导入测试02的历史副本，验证阶段筛选、草稿可见、原批准保留、问答草稿恢复和模板随批准保存。
- 在实际APP验证模型切换、两种权限设置和重连后的读回结果；临时测试会话已归档。
- 检查宽窗口、760像素窄窗口及提示位置，并调整了侧栏和终端工具栏布局。

终端设置测试验证了原生设置回执和恢复结果，没有发起额外模型推理。一次原生会话初始化失败后，通过重新连接原会话恢复，未创建替代会话。

## 使用方式

继续使用项目原来的“ABYA 开发工具”快捷方式。正式程序位于：

D:\Unity项目\ABYADesktopDevelopmentTool\Publish\ABYA Desktop Development Tool.exe

进入“制作流程”后点击顶部阶段，查看该阶段的成果与问题。终端顶部可修改模型和权限。

已有任务保留固定的工作流副本。需要应用新版完整工作流文字时，在“流程详情”中升级；本次兼容升级保留已确认决定。任务已经启动的轮次会沿用其已加载上下文，后续轮次使用更新后的配置。

## 数据与版本

正式发布通过校验过的候选包替换程序目录，旧程序目录备份到ReleaseBackups。任务数据库、工作区文件和游戏存档保留。测试02原记录未被测试副本覆盖，其游戏制作与录制复验仍从原任务当前进度继续。
