## 阶段卡点

桌面 `desktop_mcp/protocol.rs` 返回固定工具目录。工具调用使用绑定到任务和会话的凭据；任务服务再校验当前阶段、批准、隔离存档、作用范围及授权期限。设计阶段的文档可以独立提交。MCP 基线没有 CLI 版的固定基础预检模块和“提交方案时自动开 Player”的调用，因此同步时应保留文档提交路径的这一性质。需要显式预研时复用当前小样授权。

独立 PB 工作区的 `DesktopMcpCapabilityAllowlist.cs` 包含 `editor_create_archive`；`RuntimeExecutionContext.ResolveRequirement` 仍把 `editor_` 归为 Initialized + CreatorEditor。开放传输和允许当前场景执行是两个独立检查。MCP 构建进主菜单查询描述、在隔离编辑器试建和按 GUID 读回，才构成该构建的实际验证。CLI 构建的实测不能代替这一组证据。
