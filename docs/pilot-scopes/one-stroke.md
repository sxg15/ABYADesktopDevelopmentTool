# 一笔画：工作流 2.11 固定测试规格

这是预先确定的代表性测试游戏规格，用于验证原生制作流程；不是原“一笔画”项目的替代验收，也不能用于宣称原项目已完成。

## 范围

Windows 单人，鼠标操作，中文界面。六关点线谜题；一次连续拖动覆盖所有边，每条边只能走一次，节点可以重访。允许从任意节点开始，但不可跨越不存在的边。
不增加账号、联网、机器人、排行榜、商店或永久进度。保存交付关卡与玩法配置；每次冷启动从第一关开始，当前游玩中可选择已解锁关卡。

## 必要行为与验收

- REQ-01：开始页有名称、规则、开始按钮；进入第一关后节点、边和当前关卡清晰可见。
- REQ-02：必须在节点内按下左键开始；按住拖入相邻节点时才走过对应未使用边。单次移动不能跳过节点或跨越无边连接。
- REQ-03：已使用边以线型或标记及颜色共同区分；重复边不增加进度，不能靠往返刷完。
- REQ-04：拖动在画布外、失焦、松键或取消时结束当前手势；未覆盖全部边不得算过关，重新开始清除旧路径。
- REQ-05：仅全部边各走过一次时过关，显示结果与下一关按钮；最后一关显示全部完成，可以重玩或返回开始页。
- REQ-06：关卡选择仅允许当前游玩已经解锁的关卡，未解锁项不可进入；重玩不重复累计错误进度。
- REQ-07：返回和重开清除输入与旧循环；弹层出现时不触发底层按钮，连续快速点击不会生成多份关卡。
- REQ-08：在 1280×720 与 1920×1080 可读、可操作，节点与连线不互相混淆；观察路径变化须来自真实指针输入，不直接写通过状态。
- REQ-09：保存并冷加载同一交付存档，六关数据与代码完整；没有临时测试注入或调试遮挡。

## 美术与界面

浅色纸面、深色清楚的线条和圆点，已走路径使用单一强调色并配合线型。顶部显示关卡及已走边数，图形居中，底部保留重开和返回。
不要求新增插画、音频或复杂特效；节点悬停、按下、非法连接及过关须有明确反馈。交付前按固定规则审查实际运行画面。

资源阶段交付布局和状态预览；计划阶段说明图数据、输入、权威判定和表现的职责。具体实现使用当前 Player 公开能力，不预设尚未发现的接口。
