# 通用素材使用说明

素材均为独立绘制的透明 PNG（头像与纯色片除外），不含固定玩法文案。按钮文字用目标项目的文本组件叠加。

| 文件 | 用途与限制 |
|---|---|
| button-{mint,white,yellow}-{normal,hover,press,disabled}.png | 512×96，三种颜色各四态。按下图含小幅偏移，禁用只提供外观，逻辑仍需禁用输入。薄荷按钮悬停可补焦点框。斜切角不宜任意横向拉伸，优先按目标宽度重绘。 |
| card-panel.png | 688×416，浅色容器与黑色硬投影。可重新绘制或经引擎验证后切九宫格。 |
| frame-white.png | 832×832，透明内区白色边框。尺寸仅为示例，可用于预览、内容面板等；不要因素材是正方形而强制页面正方形。 |
| focus-ring.png | 128×128，薄荷绿焦点框。按目标外框重新生成或原生描边，不改变布局尺寸。 |
| ribbon-mint.png | 512×96，独立斜切标题底板，不含文字。 |
| corner-mint.png | 64×64，左上护角，可旋转用于其他角。 |
| halftone.png | 192×192，低透明度半调点纹，只放外围。 |
| icon-clock.png、icon-cup.png | 128×128，通用时间与成就图标，按需要使用。 |
| avatar-1.png 至 avatar-4.png | 96×96，原创像素头像；身份颜色随玩家绑定。 |
| solid.png | 16×16，纯白底片，供支持 tint 的组件着色。 |

原始三张图片供观察风格，不是可直接交付的界面皮肤，也不表示获得其中角色或商标的复用许可。程序生成素材未复制参考图的角色。
