# 制作与验收

## 接入现有项目

先查看组件树、字体、图片导入比例、显示属性、输入事件与滚动接口。显示适配层消费项目状态，不自行修改玩法数据。先验证一个卡片和按钮，再扩展整套皮肤。

导入资源后记录返回 ID，赋值并重新读取组件，再检查真实运行实例；本机生成 PNG 不代表已接入。图层顺序应允许背景衬托文字、装饰穿透输入。保存后重新加载，确认资源仍可用。

透明 PNG 边框不能任意拉伸。确认目标引擎的九宫格、锚点与 pixelsPerUnit 约定，按目标重建或改为原生图形；包内尺寸为素材尺寸，不是所有引擎的强制导入单位。像素头像用最近邻缩放，其余素材根据实际边缘质量选择过滤。

## 来自实际制作的通用经验

- 布局单位与字体单位可能不同。先校准一个标题和一个数值，避免重复缩小字体。
- 大号数字可能因文本框高度不足及 Ellipsis 设置而整体消失。按字体行高扩大容器；Overflow 只用于确认不会碰到相邻元素的情况，长姓名仍应截断。
- visible 与 display 可能独立控制显示。初始化与阶段切换都检查完整显示条件，清理上一次操作的提示。
- 动画只改变视觉；切换页面、回合或数据版本时取消旧回调，不让动画阻塞网络消息或状态处理。
- 按下皮肤不等于完整的按压交互。验证释放、取消、移出和状态切换时的复位；移动端防止一次触摸重复触发。
- 多显示器与 DPI 下，工具坐标未必等于物理屏幕坐标。先校准客户区与缩放，再判断点击是否命中。
- 列表翻页按钮不等于滚轮或触摸滚动。按用户要求实现并分别验证。

## 验收矩阵

| 范围 | 可见结果 |
|---|---|
| 默认、悬停、按下、禁用 | 状态可辨，边框不挤布局，禁用确实不可操作 |
| 选中与焦点 | 与悬停区分；焦点不只依赖颜色 |
| 文字与数值 | 实际尺寸下可读，字体回退、长名和多位数不越界 |
| 页面阶段 | 当前阶段操作明确，没有上一阶段提示残留 |
| 身份与列表 | 身份色稳定，本人标识清楚，滚动不挤主区域 |
| 反馈 | 错误、完成提示可辨；不改变原有输入和状态规则 |
| 分辨率 | 目标与最小目标窗口均无重叠裁切，图标比例正确 |
| 资源 | 无缺图，透明边缘干净，保存重载后仍正确 |

截图和节点矩形结合检查：矩形在父节点内不代表字形没有溢出。静态展示夹具注明用途，不将其当成真实输入、计时或联网的证据。不要为截图延长正式动画时长。按目标设备分别记录鼠标、键盘与触屏实测范围。
