## 美术模板入口

本 Skill 只定义视觉风格，不替代玩法任务流程。遵循同级 ../abya-game-development-task/SKILL.md 的评估后美术选择流程；用户明确选择后再加载本模板及参考素材。保持已确认的玩法、设备和输入契约。项目或任务指定的字体优先于下文的字体建议；ABYA 多人任务的文本自由物体和 CustomUI 必须使用 DingTalk，不因粗体黑体或等宽数字建议换用其他字体。随包素材是可复用来源，须按实际接口导入、赋值、读回并完成实机验收，不能仅复制文件。


# 漫画街机界面制作

先实际查看随包的三张[原始风格参考](references/visual-language.md)和[素材预览](风格参考.html)，再提取适合当前项目的视觉语法。不要照搬参考图片中的游戏场景、规则文案或固定布局。

## 工作顺序

1. 读取目标项目的页面与组件状态，明确主要操作、核心信息、辅助内容。沿用项目已有玩法和数据契约。
2. 先完成一个最小可运行组件：默认、悬停、按下、选中、禁用。用底色、轮廓和图标区分语义，不仅改变透明度。
3. 再安排主操作区与信息栏，按页面阶段显示配置和操作。以真实窗口校准字号、间距与锚点，不将整个画面烘焙为一张背景图。
4. 复用随包按钮、卡片、框线和图标；文字保持独立文本层。像素风集中用于头像或小图标，正文用清晰粗体黑体，核心数值用等宽数字。
5. 最后添加外围斜切飘带、薄荷绿护角和低对比半调装饰，避免遮挡内容。动画服务于状态反馈，不能改变底层计时、输入和结算。
6. 按[制作验收清单](references/production-checklist.md)检查真实运行画面与输入，记录未验证项。静态素材预览不等于实机验收。

## 资源选择

- [视觉语言](references/visual-language.md)：原始参考、视觉分析与通用适配方式。
- [设计变量](assets/design-tokens.json)：建议色板、几何和动效起点；按设备调整，非强制像素值。
- [素材目录与使用说明](references/asset-guide.md)：透明 PNG 的用途、尺寸和缩放边界。
- [制作验收](references/production-checklist.md)：资源导入、文本可读性、状态同步与输入测试。
- [来源清单](references/materials.json)：原始参考与独立绘制素材的路径、哈希。用户参考图的授权范围不能由本包推定。

需要重建素材时运行 `python scripts/make-ui-kit.py --output <新目录>`，依赖 Pillow。现成素材可直接使用，无需先运行脚本。所有路径相对本 Skill，复制整个文件夹即可携带资源。

薄荷绿用于强调或选中，黄色用于高优先级行动，红色用于错误或警告。颜色含义服从当前产品，不绑定固定玩法。身份色跟随稳定玩家身份，不随排名变化。成功状态只来自真实业务结果，装饰不能暗示未经验证的正确性。
