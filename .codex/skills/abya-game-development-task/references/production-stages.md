# 制作阶段（流程 2.0）

只执行用户要求的范围。完整任务按下列顺序；局部修改不重新发起整套流程。
先读 production get 的固定 policy；旧任务未显式升级时仍遵守其旧策略，保留历史和批准。

## 1. 需求 → 确认需求文档

沿用已明确的提问模式、人数、目标、规则、设备、输入、页面状态和素材范围。
允许提问且存在产品歧义时，通过 publish-questions 发布当前阶段的问题组，然后结束本轮等待。
不循环轮询、不要求先暂停，不让策划重复已经提交的答案。问答不等于文档确认。
模板只读取摘要与实际选中项；明确选择复用，否则把建议纳入需求文档。
使用稳定 REQ 编号列核心循环、胜负、退出重开、必要页面、验收条件和不包含的内容。
提交 requirements 文档，由 APP 确认其具体版本，才推进资源与方案。

## 2. 资源与美术预览

优先复用现有资源和明确选中的模板；需要新增资源时按当前授权范围制作。
提供素材预览板、整体布局、关键状态预览；一张组合图可覆盖多个用途，不强制三张。
默认一套主要方案，存在明确风格分歧才补少量候选，不无限制作风格备选。
参考图、设计示意、引擎渲染、游戏实拍分别标注；临时资源注明临时和替换安排。
资源阶段可做组合示意及独立资源预览，不提前实现完整玩法来生成所谓最终截图。
涉及必要动作或特效时提供短视频；静态素材不强制录像。
用 register-visual 登记实际文件、用途、来源和方案版本；保持旧文件不被覆盖。
完成 resources 后，视觉方案随执行计划一起确认，不增加第四个强制批准节点。

## 3. 方案、选型与预检 → 确认执行计划

查实际 Player/CLI、存档/关卡、公开 API、字体、测试拓扑和本次需要的取证能力。
既有验证可在运行包、能力版本与目的未改变时复用，记录依据；不要每次重复调查。
必要运行能力缺失时阻塞相关工作，并继续不受影响的事项。录像仅在当前验证确实需要时成为前置。
源码存在不等于运行包具备能力；玩法任务不自动获得修改宿主或扩大需求范围的授权。
计划对应 REQ，说明职责、实现顺序、素材、风险专项、验收运行包和恢复方式。
先整体界面与必要交互，再补复杂表现；尽早形成完整可玩版本，不先精修局部装饰。
提交 plan 时绑定当前资源预览版本，等 APP 确认；普通内部实现选择不重复请求批准。

## 4. Lua 实现与必要自测

按 [运行与实现](runtime-authoring.md) 校验、绑定、保存、读回和冷加载。
完成确认范围的完整循环、页面、资源及输入，不能把缺核心功能的版本交给策划补验。
登记真实版本，通过 save-self-test 保存 architecture、lua、core-loop、input、visual、
lifecycle、save-reload、authority 的实际结果。单人任务 authority 可说明不适用。
有风险的时限、计分、同步等增加针对性检查，不机械穷举与当前修改无关的组合。
必要验证通过后 complete-stage implementation，立即进入人工试玩，不执行固定十二轮。
用 register-visual 回填游戏实拍/效果视频，与确认方案对照，证据说明真实操作与查看范围。

## 5. 人工试玩 → 修改 → 相关复验

读取 [反馈迭代](whole-experience-review.md)。登记验收配置，使用 production start-acceptance
打开当前版本；该入口复用正式 APP 的版本检查、成对启动和初始化检查。
人工操作期间停止自动输入。策划反馈由 APP 保存，关联版本、实例及图片/视频。
反馈属于缺陷则修复并复验，新增范围则修订受影响文档；不重新确认无关需求。
修改后的新版本登记实际指纹，受影响证据重测，未受影响证据可声明依据后复用。
AI只标记处理中或修复后待策划复验，不能关闭策划反馈或代替用户接受作品。

## 6. 最终作品确认与收尾

必要检查有效、必要问题和反馈已处理后提交 delivery，关联当前实际版本与试玩方式。
只有策划接受该版本，才进入 closeout。对话结束、自测通过、窗口打开都不等于验收通过。
整理范围、剩余限制、资源来源、维护入口、实际用时与可复用经验，生成固定报告。
按授权范围整理本任务资料；保留历史，不清理共享资源，不自动发布公共 Skill/APA。
提交 closeout 和知识记录，完成收尾后再将任务标为完成。

## 进度、预算与恢复

开工时在顶部对话步骤登记本轮工作，实际结果回来再勾完成；阶段进展用 update-stage。
常规同规模、环境正常任务以 3–4 小时推进时间为目标，不包含策划等待，不保证无限新增范围。
记录总历时、人工等待、推进、平台阻塞和返工；工具时间是推进子集，不重复相加。
遇到平台故障或预算明显超出，说明具体原因与剩余工作，不通过删减验收假装提速。
中断后读取已有产物和最新反馈，从未完成处继续；有效证据不因换会话而作废。
