# 运动规则与复现

数值和具体粒子初值读取 `assets/effects.json`。可执行的跨引擎参考为 `scripts/effect_math.py`，仅输出表现状态，任何引擎可照公式实现，不依赖 Python 运行时。

所有插值以真实经过时间计算，不能按“每帧加固定值”推进。GIF 以 20 ms 为采样步长，编码器可合并相同帧；合并后帧数较少不表示效果降低为同样帧率。

## 公共函数

`clamp(x)=min(1,max(0,x))`。

`smooth(x)=clamp(x)^2 × (3−2×clamp(x))`。

alpha 是素材自身 alpha 的乘数，不能替换其蜡笔空隙。纸片正反面用同一形状，反面是浅奶油色混合，翻面时保持原垂直尺寸；水平投影最小宽度只是预览防止消失的表现参数。

## 勾叉

按归一化进度 p 先由小放大至轻微过冲，再回落到正常比例。开头快速显现，尾段平滑淡出，终点清为零。参考采用整枚印记出现，没有逐笔书写，也没有错误震屏。预览文字“答对 +5 / 答错 −5”不属于特效资产；计分数值与文本由工程提供。

## 纸片爆开

每片有各自的延迟、方向、初速度、阻力、尺寸、翻面相位、角速度及寿命；具体初值附在 JSON。

以该片 age 为时间：阻力位移为 `(1−exp(−drag×age))/drag`。X 用方向速度乘位移再叠轻微摆动；Y 用方向速度乘位移再加向下的二次项。这样爆发后自然变慢并略微回落。

每片的 alpha 先快速显现，再从它自己寿命的 45% 开始到寿命末尾持续平滑淡出。不要将全部粒子年龄除以统一的 0.3 秒，也不要在 300 ms 时调用整组 stop/clear。

纸片绕面内旋转并通过 cosine 表现正反翻转；cosine 为负时使用反面纹理并水平镜像。总效果容器保留到配置总时长，以容纳最后一片的延迟和寿命。按钮文字绘制在纸片前面，是参考 GIF 避免遮挡的实际分层关系。

## 折页切换

先短暂保留旧面，然后将完整纸页沿竖轴收窄到折线；过半切换到新面，再展开。投影宽度与 `abs(cos(pi×q))` 成比例，页高和明暗只有小幅变化。参考使用一次完整页的投影变换，不是把两半数字拼成混合内容，也不把新旧两面交叉透明叠加。

参考 GIF 包含最后的新面停留，以及为了重复播放而设计的“淡到空白再复位”。实装只执行一次过渡并保留新面，不能把演示复位、循环空档写进效果状态机。
