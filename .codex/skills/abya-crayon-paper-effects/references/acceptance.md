# 接入验收

先运行包内校验，再在目标工程用相同视口、内容和时刻进行比对。包内校验不替代实机。

| 对象 | 必须看见的结果 |
|---|---|
| 勾/叉 | 轮廓与原透明图一致；纹理仍能透出底图；快速出现、轻回弹、自然淡出；不遮计时与比分 |
| 纸片爆开 | 点击位置明确；300 ms 之后仍有尾部；各片先后淡出；最后不是整批删掉；纸片在文字后方 |
| 折页 | 只显示一个内容面；收窄后换面；展开到稳定的新内容；正式场景中不自动复位 |
| 共通 | 连续触发不重复计分、不改变命中框；停止/卸载后无残留；缩放后比例与材质不漂移 |

纸片重点截图：100、300、500、700、900、1020 ms。前五点应呈现从爆发到稀疏余韵的连续变化，最后清空。不要仅截首尾两张后宣称动态已通过。

折页重点检查：动作开始、收窄中、换面附近、展开结束及保留新内容。手动关闭或外部状态覆盖时，应恢复到当前逻辑内容，不能出现两组数字或回滚。

在目标平台正常速度与较慢速度分别观察；至少覆盖原生比例、小尺寸、快速连续触发和场景退出。有多人独立玩家区域时，核对触发与清理不会串到他人区域。低帧率按项目支持范围验证，不能将离线 50 fps GIF 视为性能保证。

这套库已进行的检查：预览关键帧审阅、导出 GIF 解码后的标题/页脚保护与循环接缝检查、爆开尾部变化检查。纸片修订版在参考导出中 300 ms 仍接近峰值、900 ms 仅有微弱尾部，约 1 秒清空。此为图像检查，非所有渲染器的硬阈值。

当前用户已选择这四款入库。目标工程完成后仍需报告：实际资源与版本、触发位置、时序/图层适配、实机截图或录像、与基准的差异，以及未验证项。不要把入库选择扩写成目标工程验收通过。
